# _**Algebro**_: The Interactive Algebra Tutor
## Algebro is a tutoring program for highschool students, aided by Machine Learning to help solidify and build their algebra skills.
### (Originally a group project for a System Analysis and Design Class)
>
>
>
## Run instructions:

1. Navigate to the source folder: ```cd Algebro/src```
2. Run the program: ```python algebro_gui.py```

## User Functionality:
* Teachers:
  * Create, View, Manage Classes
  * Import Problemsets
* Students:
  * Register for Class
  * Complete Problemsets
  * View Progress
* General User
  * Sign up without Class
  * Complete Problemsets
  * View Progress
